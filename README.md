These are the steps to use our system:

STEP 1:
Extract the zip file to an unpopulated folder.

STEP 2:
Open the folder in a text editor, preferrably Visual Studio Code.

STEP 3:
Use the command "php artisan storage:link" in the terminal.

STEP 4:
Use the command "php artisan serve" to host the system in your local device.

STEP 5: 
Enjoy using and experimenting with the Bulldogs Exchange (BDX).
